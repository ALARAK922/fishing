      使用说明

      1. 图例：★ 黄色星标 = 毒区钓点；🎣 绿色标记 = 其他钓点。点击标记查看描述。
      2. 添加标点：打开 js/spots.js，复制一行 { ... } 填入名称和坐标即可。
      3. 拿坐标：高德/百度地图上的坐标不能直接用（有偏移），添加新标点前请用配套工具 convert.html（坐标转换） 转换。
      4. 查看标点：点击地图上的标记查看详情；左侧列表可快速定位；左上角「🌍 外地」查看非上海钓点。
      5. 切换底图：右上角按钮可在街道图 / 卫星图之间切换（卫星图看河岸、水闸更直观）。
